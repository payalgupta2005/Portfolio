# Payal Gupta — Portfolio

A modern, responsive personal portfolio website built with **React.js** and **CSS** to showcase my skills, projects, experience, and journey as a developer.

## 🚀 Live Demo

🌐 Portfolio: https://payalgupta-portfolio.vercel.app/

## 🛠 Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Icons
- Framer Motion

## ✨ Features

- Responsive design for all devices
- Modern dark/light theme UI
- Smooth animations and transitions
- Skills and project showcase
- Resume download option
- Contact form integration

## 📂 Sections

- Home
- About
- Skills
- Experience
- Projects
- Contact
